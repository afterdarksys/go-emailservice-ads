# Phase 1.1 — High-Priority Security Fixes (P1)
_Milestone: M1 | Estimated effort: 2–3 days_

## Goal
Eliminate P1 security vulnerabilities: SPF softfail handling, bounce loop prevention,
safe message ID generation, non-blocking queue sends, MailScript SSRF, and execution
timeouts.

## Success Criteria
- [ ] SPF softfail messages receive `X-SPF-Status: softfail` header and are scored
- [ ] Bounce messages are never sent to null/empty envelope senders
- [ ] Message IDs are UUID v4 (verified with regex `[0-9a-f]{8}-...-...`)
- [ ] `Enqueue()` never blocks for longer than 100ms
- [ ] MailScript `http_get` rejects private IP ranges and non-HTTPS URLs
- [ ] Policy scripts that exceed 1M Starlark steps are terminated with an error action
- [ ] Legacy SMTP server requires TLS 1.2 minimum

### 1.1.4 — Non-blocking Enqueue with graceful backpressure
**File**: `internal/smtpd/queue.go:449-464`

```go
func (qm *QueueManager) enqueueToChannel(tier QueueTier, msg *Message) error {
    ch := qm.channelForTier(tier)
    select {
    case ch <- msg:
        return nil
    case <-time.After(100 * time.Millisecond):
        // Message is already persisted to DB — safe to return success.
        // The retry scheduler will requeue it.
        qm.logger.Warn("Queue channel full — message will be retried from store",
            zap.String("tier", string(tier)),
            zap.String("msg_id", msg.ID))
        qm.updateMetrics(tier, "backpressure")
        return nil // do NOT return error — SMTP client gets 250 OK, retry picks it up
    case <-qm.ctx.Done():
        return fmt.Errorf("queue shutting down")
    }
}
```

Replace the raw `qm.intQ <- msg` sends with `qm.enqueueToChannel(msg.Tier, msg)`.
Add a `backpressure` metric counter to `QueueMetrics`.

### 1.1.5 — MailScript SSRF protection
**File**: `internal/mailscript/engine.go:151-173`

```go
func isAllowedURL(rawURL string) error {
    u, err := url.Parse(rawURL)
    if err != nil {
        return fmt.Errorf("invalid URL: %w", err)
    }
    if u.Scheme != "https" {
        return fmt.Errorf("only HTTPS URLs are permitted in http_get")
    }
    host := u.Hostname()
    ips, err := net.LookupHost(host)
    if err != nil {
        return fmt.Errorf("hostname lookup failed: %w", err)
    }
    for _, ipStr := range ips {
        ip := net.ParseIP(ipStr)
        if ip == nil { continue }
        if ip.IsLoopback() || ip.IsPrivate() || ip.IsLinkLocalUnicast() ||
            ip.IsLinkLocalMulticast() || isMetadataIP(ip) {
            return fmt.Errorf("URL resolves to private/reserved address: %s", ipStr)
        }
    }
    return nil
}

func isMetadataIP(ip net.IP) bool {
    // AWS/GCP/Azure metadata service IPs
    metadataRanges := []string{
        "169.254.169.254/32",  // AWS/GCP/Azure IMDS
        "169.254.170.2/32",    // ECS task metadata
    }
    for _, cidr := range metadataRanges {
        _, ipNet, _ := net.ParseCIDR(cidr)
        if ipNet.Contains(ip) { return true }
    }
    return false
}
```

Add size limit to response body:
```go
bodyBytes, err := io.ReadAll(io.LimitReader(resp.Body, 64*1024)) // 64KB max
```

### 1.1.6 — MailScript execution timeout via step limit
**File**: `internal/mailscript/engine.go:59-108`

Starlark supports step-based cancellation. Add to `ExecutePolicy`:
```go
const maxStarlarkSteps = 1_000_000

thread := &starlark.Thread{
    Name: "mailscript_thread",
    // Called on each step; return non-nil error to abort
}
thread.SetMaxSteps(maxStarlarkSteps)
```

When `starlark.EvalError` wraps a step-limit error, return a logged warning
and `ActionAccept` (fail open, do not reject mail due to script timeout):
```go
if strings.Contains(err.Error(), "step limit") {
    e.logger.Error("MailScript exceeded step limit", zap.String("script", scriptName))
    return &MailAction{Deliver: true}, nil // fail open
}
```

Also add a wall-clock timeout as a second defense:
```go
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()
// pass ctx to thread via thread.SetLocal("ctx", ctx) or use a channel
```
