# Phase 1.0 — Critical Security Fixes (P0)
_Milestone: M1 | Estimated effort: 3–4 days_

## Goal
Eliminate all P0 security vulnerabilities identified in the architecture review. No
message should be accepted, delivered, or authenticated using broken/stub code paths.

## Success Criteria
- [ ] No hardcoded credentials anywhere in the codebase (`git grep -r "securepassword"` returns nothing)
- [ ] Local mail recipients receive stored messages verifiable via IMAP FETCH
- [ ] ARC headers on inbound mail are properly verified (invalid chains rejected in strict mode)
- [ ] DKIM result from verification is present in the policy EmailContext before Evaluate()
- [ ] DMARC correctly rejects mail where neither SPF nor DKIM aligns with RFC5322.From domain
- [ ] All existing tests pass; new unit tests added for each fix

### 1.0.3 — Implement real ARC chain verification
**File**: `internal/security/arc.go:332-339`
**Risk**: CRITICAL — ARC forgery accepted

Remove stub implementations. The ARC-Seal and ARC-Message-Signature headers carry
base64-encoded RSA signatures that must be verified against the public key fetched
from DNS (selector._domainkey.domain TXT record), same as DKIM.

Implementation steps:
1. Add `resolver *dns.Resolver` to `ARCManager`
2. In `verifySeal(set ARCSet, ...)`:
   - Parse `a=`, `d=`, `s=`, `b=` fields from `set.ARCSeal`
   - Fetch public key: `LookupTXT(ctx, selector+"._domainkey."+domain)`
   - Parse RSA public key from `p=` field in TXT record
   - Reconstruct the signed data (all ARC headers up to but not including `b=` value)
   - Verify: `rsa.VerifyPKCS1v15(pubKey, crypto.SHA256, hash, sigBytes)`
3. Repeat for `verifyMessageSignature` (verifies the message header set)
4. Fix `rsa.SignPKCS1v15(nil, ...)` → `rsa.SignPKCS1v15(rand.Reader, ...)`
5. Fix `getChainValidation` to actually verify prior sets before claiming "pass"

Leverage `emersion/go-msgauth/dkim` internals — ARC signing is structurally identical
to DKIM and the library has helpers for header canonicalization.

### 1.0.5 — Fix DMARC identifier alignment
**File**: `internal/security/spf_dmarc.go:326-331`
**Risk**: CRITICAL — impersonation bypass

RFC 7489 §3.1: For SPF to satisfy DMARC, the domain in the `MAIL FROM` (RFC5321.MailFrom)
or HELO must align with the RFC5322.From header domain. Alignment modes:
- **relaxed** (default): organizational domain match (`mail.example.com` aligns with `example.com`)
- **strict**: exact domain match only

```go
// VerifyDMARC must accept the RFC5322.From domain and the SPF-authenticated domain separately
func (p *PolicyEngine) VerifyDMARC(
    ctx context.Context,
    fromHeaderDomain string,  // parsed from RFC5322.From header
    envelopeFrom string,      // RFC5321.MailFrom (SPF domain)
    heloHostname string,
    spfResult SPFResult,
    spfDomain string,         // domain SPF actually authenticated
    dkimResults []DKIMResult, // all verified DKIM domains
    alignMode string,         // "relaxed" or "strict" per adkim=/aspf= tags
) (DMARCResult, DMARCPolicy, error) {

    // SPF alignment check
    spfAligned := domainsAlign(fromHeaderDomain, spfDomain, alignMode)
    spfPass := spfResult == SPFPass && spfAligned

    // DKIM alignment check — any passing DKIM signature that aligns counts
    dkimPass := false
    for _, dkimResult := range dkimResults {
        if dkimResult.Pass && domainsAlign(fromHeaderDomain, dkimResult.Domain, alignMode) {
            dkimPass = true
            break
        }
    }

    dmarcPass := spfPass || dkimPass
    ...
}

func domainsAlign(fromDomain, authDomain, mode string) bool {
    if mode == "strict" {
        return strings.EqualFold(fromDomain, authDomain)
    }
    // relaxed: compare organizational domains
    return orgDomain(fromDomain) == orgDomain(authDomain)
}

func orgDomain(d string) string {
    // Strip subdomains: mail.example.com -> example.com
    // Use public suffix list for correctness (golang.org/x/net/publicsuffix)
    eTLD, _ := publicsuffix.EffectiveTLDPlusOne(d)
    return strings.ToLower(eTLD)
}
```

Add `golang.org/x/net/publicsuffix` (already transitively available via `golang.org/x/net`).
