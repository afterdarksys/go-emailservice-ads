# Phase 4.0 — Classic Spam Control Engine
_Milestone: M4 | Estimated effort: 8–10 days_

## Goal
Build a multi-layer, scored spam control pipeline that integrates at SMTP time
(connection, EHLO, MAIL FROM, RCPT TO, DATA phases) and post-queue (async
content analysis). Replace the SHA256-only outbreak engine with fuzzy hashing.

## Architecture

```
SMTP Connection
      │
      ├── [L1] Connection Reputation
      │         IP DNSBL (Spamhaus ZEN, Barracuda, SORBS)
      │         PTR/EHLO mismatch check
      │         Connection rate limiting
      │
      ├── [L2] Envelope Reputation (MAIL FROM / RCPT TO)
      │         Domain DNSBL (SURBL, URIBL, Spamhaus DBL)
      │         BATV / SRS bounce validation
      │         Null sender abuse detection
      │         Recipient histogram (too many rcpt → bulk signal)
      │
      ├── [L3] Message Content (DATA)
      │         SPF/DKIM/DMARC (existing, now wired)
      │         URL extraction + URIBL lookup
      │         YARA rules (ClamAV optional)
      │         Fuzzy hash clustering (TLSH)
      │         Header anomaly scoring
      │         AI scoring (Phase 5 — async)
      │
      └── [L4] Composite Score Decision
                score < 3.0  → ACCEPT
                score 3-6    → TAG (X-Spam-Score, X-Spam-Flag)
                score 6-8    → QUARANTINE (deliver to Spam folder)
                score > 8    → REJECT (550)
```

### 4.1.2 — PTR / EHLO anomaly scoring
**New file**: `internal/reputation/helo.go`

```go
type HELOAnalyzer struct{}

func (h *HELOAnalyzer) Score(ip net.IP, heloHostname string) (float64, []string) {
    var score float64
    var reasons []string

    // 1. PTR lookup for connecting IP
    ptrs, _ := net.LookupAddr(ip.String())

    // 2. No PTR record
    if len(ptrs) == 0 {
        score += 1.5
        reasons = append(reasons, "no-ptr-record")
    }

    // 3. PTR exists but doesn't forward-confirm to same IP (FCrDNS)
    for _, ptr := range ptrs {
        ips, _ := net.LookupHost(strings.TrimSuffix(ptr, "."))
        confirmed := false
        for _, resolvedIP := range ips {
            if resolvedIP == ip.String() { confirmed = true; break }
        }
        if !confirmed {
            score += 1.0
            reasons = append(reasons, "fcrdns-fail")
        }
    }

    // 4. EHLO is an IP address literal (suspicious for outbound)
    if strings.HasPrefix(heloHostname, "[") {
        score += 1.0
        reasons = append(reasons, "helo-ip-literal")
    }

    // 5. EHLO hostname doesn't match PTR (mismatch)
    if len(ptrs) > 0 && !hostnameMatchesPTR(heloHostname, ptrs) {
        score += 0.5
        reasons = append(reasons, "helo-ptr-mismatch")
    }

    return score, reasons
}
```

## Phase 4.2 — Content Scoring

### 4.2.1 — URL extraction and URIBL check
**New file**: `internal/reputation/url_scanner.go`

Extract all URLs from:
1. `text/plain` MIME parts (regex)
2. `text/html` MIME parts (HTML parser → `<a href>`, `<img src>`)
3. Expand redirects (1-hop only, 2s timeout)

For each extracted domain:
- Check against SURBL (`domain.multi.surbl.org`)
- Check against URIBL (`domain.uribl.com`)
- Check against Spamhaus DBL (`domain.dbl.spamhaus.org`)

Limit: max 20 URLs per message to prevent DoS.

### 4.2.2 — Fuzzy hash outbreak detection (replace SHA256)
**New file**: `internal/reputation/fuzzy_hash.go`

Replace `internal/security/spread_prevention.go` with TLSH-based clustering.

**TLSH (Trend Micro Locality Sensitive Hash)**:
- Produces a 72-byte hash with structural locality properties
- Two hashes with TLSH distance < 30 are "essentially the same message"
- Available as pure Go: implement the TLSH algorithm (~400 lines)

```go
type FuzzyOutbreakEngine struct {
    logger       *zap.Logger
    burstWindow  time.Duration
    threshold    int
    mu           sync.RWMutex
    clusters     map[string]*outbreakCluster  // TLSH hash → cluster
    // Distributed: sync cluster state via Redis pub/sub
    redis        *redis.Client  // optional, nil = local only
}

type outbreakCluster struct {
    Hash       string
    FirstSeen  time.Time
    Count      int
    LastSeen   time.Time
    Quarantine bool
}

func (e *FuzzyOutbreakEngine) Evaluate(body []byte) (bool, string) {
    // 1. Compute TLSH hash of body (ignore headers for clustering)
    tlshHash := tlsh.Hash(extractBody(body))
    
    // 2. Find nearest existing cluster (distance < 30)
    clusterID := e.findOrCreateCluster(tlshHash)
    
    // 3. Increment count, check threshold
    return e.checkThreshold(clusterID), clusterID
}
```

TLSH distance algorithm (pure Go implementation plan):
- Bucket histogram of byte values (256 buckets, 4-bit entries)
- Checksum: 1-byte Pearson hash
- Q1 and Q2 quartile values
- Distance = bucket distance + length distance + checksum distance

### 4.2.3 — Header anomaly scoring
**New file**: `internal/reputation/header_analyzer.go`

Score based on RFC 5322 violations and suspicious patterns:

| Signal | Score |
|--------|-------|
| Missing `Message-ID` | +1.0 |
| Missing `Date` | +1.5 |
| `Date` > 24h in past or future | +1.0 |
| Multiple `From` headers | +2.0 |
| `From` display name contains URL | +1.5 |
| `Reply-To` domain differs from `From` domain | +0.5 |
| Excessive `Received` hops (> 8) | +0.5 |
| `Received` timestamp reverse order | +1.0 |
| `X-Mailer` matches known spam tools | +2.0 |
| HTML-only message (no text/plain) | +0.5 |
| Suspicious subject (ALL CAPS, excessive `!!!!`) | +0.5 |
| Base64 encoded text/plain | +0.5 |
| Mismatched MIME boundaries | +1.5 |

## Phase 4.3 — Composite Scoring Engine

### 4.3.1 — Scoring pipeline
**New file**: `internal/reputation/scorer.go`

```go
type ScoreResult struct {
    Total      float64
    Components map[string]float64  // component name → score contribution
    Decision   SpamDecision
    Reasons    []string
    Action     SpamAction
}

type SpamDecision string
const (
    DecisionAccept     SpamDecision = "accept"
    DecisionTag        SpamDecision = "tag"
    DecisionQuarantine SpamDecision = "quarantine"
    DecisionReject     SpamDecision = "reject"
)

type ScoringEngine struct {
    dnsbl     *DNSBLChecker
    helo      *HELOAnalyzer
    urlScan   *URLScanner
    fuzzy     *FuzzyOutbreakEngine
    headers   *HeaderAnalyzer
    thresholds ScoringThresholds
}

type ScoringThresholds struct {
    Tag        float64 // default 3.0
    Quarantine float64 // default 6.0
    Reject     float64 // default 8.0
}

func (e *ScoringEngine) ScoreConnection(ctx context.Context, ip net.IP, helo string) *ScoreResult
func (e *ScoringEngine) ScoreEnvelope(ctx context.Context, from, to string) *ScoreResult
func (e *ScoringEngine) ScoreMessage(ctx context.Context, data []byte, prior *ScoreResult) *ScoreResult
```

### 4.3.2 — Wire scoring into SMTP session
In `Session.NewSession` (connection phase): run `ScoreConnection`, store on session.
In `Session.Mail` (MAIL FROM): run `ScoreEnvelope`, accumulate.
In `Session.Data`: run `ScoreMessage`, make final decision.

Add `X-Spam-Score`, `X-Spam-Status`, `X-Spam-Flag`, `X-Spam-Report` headers to tagged messages.
Route quarantined messages to `Spam` or `Junk` folder via Sieve `fileinto`.
