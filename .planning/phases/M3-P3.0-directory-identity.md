## Phase 3.1 — LDAP Group Resolution

### 3.1.1 — Implement LDAPProvider using go-ldap
**File**: `internal/routing/groups/ldap.go`

```go
import "github.com/go-ldap/ldap/v3"

type LDAPProvider struct {
    logger     *zap.Logger
    config     *LDAPConfig
    pool       *ldapConnectionPool
}

type LDAPConfig struct {
    Server      string   // ldap://dc.corp.example.com:389
    BindDN      string   // cn=mailservice,ou=ServiceAccounts,dc=corp,dc=example,dc=com
    BindPass    string   // from vault/secret env
    BaseDN      string   // dc=corp,dc=example,dc=com
    UserFilter  string   // (&(objectClass=user)(mail={email}))
    GroupFilter string   // (&(objectClass=group)(member={dn}))
    EmailAttr   string   // mail
    MemberAttr  string   // member (AD) or memberUid (OpenLDAP)
    UseTLS      bool     // LDAPS or StartTLS
    SkipVerify  bool     // false in production
}

func (lp *LDAPProvider) GetMembers(ctx context.Context, group *Group) ([]string, error) {
    conn, err := lp.pool.Get()
    if err != nil {
        return nil, fmt.Errorf("LDAP pool error: %w", err)
    }
    defer lp.pool.Put(conn)

    // Search for group object, get member DNs
    searchReq := ldap.NewSearchRequest(
        lp.config.BaseDN,
        ldap.ScopeWholeSubtree, ldap.NeverDerefAliases,
        0, 30, false,
        fmt.Sprintf("(&(objectClass=group)(cn=%s))", ldap.EscapeFilter(group.Name)),
        []string{lp.config.MemberAttr},
        nil,
    )

    result, err := conn.SearchWithPaging(searchReq, 1000)
    if err != nil {
        return nil, fmt.Errorf("LDAP search failed: %w", err)
    }

    // For each member DN, resolve their email address
    var emails []string
    for _, entry := range result.Entries {
        for _, memberDN := range entry.GetAttributeValues(lp.config.MemberAttr) {
            email, err := lp.resolveMemberEmail(conn, memberDN)
            if err != nil { continue }
            emails = append(emails, email)
        }
    }
    return emails, nil
}
```

### 3.1.2 — LDAP connection pool
Implement a simple pool using a buffered channel of `*ldap.Conn`:
- Pool size: 10 connections (configurable)
- Health check: periodic `(*ldap.Conn).Search` with `(objectClass=*)` on base DN
- Reconnect on broken connections (detect via `ldap.IsErrorWithCode`)
- Bind credentials from environment variable (`LDAP_BIND_PASS`) or Vault

### 3.1.3 — LDAP authentication backend
**File**: `internal/auth/auth.go` — new `LDAPAuthBackend`

```go
type LDAPAuthBackend struct {
    config *LDAPConfig
    logger *zap.Logger
}

func (b *LDAPAuthBackend) Authenticate(username, password string) (*User, error) {
    conn, err := ldap.DialURL(b.config.Server)
    if err != nil { return nil, err }
    defer conn.Close()

    if b.config.UseTLS {
        if err := conn.StartTLS(&tls.Config{MinVersion: tls.VersionTLS12}); err != nil {
            return nil, fmt.Errorf("StartTLS failed: %w", err)
        }
    }

    // First bind as service account to find user DN
    if err := conn.Bind(b.config.BindDN, b.config.BindPass); err != nil {
        return nil, fmt.Errorf("service bind failed: %w", err)
    }

    // Search for user by email or username
    searchReq := ldap.NewSearchRequest(
        b.config.BaseDN, ldap.ScopeWholeSubtree, ldap.NeverDerefAliases,
        1, 10, false,
        fmt.Sprintf(b.config.UserFilter, ldap.EscapeFilter(username)),
        []string{"dn", "mail", "displayName"},
        nil,
    )
    result, err := conn.Search(searchReq)
    if err != nil || len(result.Entries) == 0 {
        return nil, ErrUserNotFound
    }

    userDN := result.Entries[0].DN

    // Bind as the user to verify password
    if err := conn.Bind(userDN, password); err != nil {
        return nil, ErrInvalidCredentials
    }

    return &User{
        Username: username,
        Email:    result.Entries[0].GetAttributeValue("mail"),
        Enabled:  true,
    }, nil
}
```

## Phase 3.2 — OIDC / SAML SSO

### 3.2.1 — OIDC token validation
**File**: `internal/auth/sso.go`

Add OIDC discovery and JWKS-based token validation:
```go
import "golang.org/x/oauth2/oidc"

type OIDCProvider struct {
    verifier *oidc.IDTokenVerifier
    config   *OIDCConfig
}

type OIDCConfig struct {
    IssuerURL    string // https://login.microsoftonline.com/{tenant}/v2.0
    ClientID     string
    EmailClaim   string // "email" or "preferred_username"
}

func NewOIDCProvider(ctx context.Context, cfg *OIDCConfig) (*OIDCProvider, error) {
    provider, err := oidc.NewProvider(ctx, cfg.IssuerURL)
    if err != nil { return nil, err }
    return &OIDCProvider{
        verifier: provider.Verifier(&oidc.Config{ClientID: cfg.ClientID}),
        config: cfg,
    }, nil
}

func (p *OIDCProvider) ValidateToken(ctx context.Context, rawToken string) (string, error) {
    idToken, err := p.verifier.Verify(ctx, rawToken)
    if err != nil { return "", err }
    var claims struct{ Email string `json:"email"` }
    if err := idToken.Claims(&claims); err != nil { return "", err }
    return claims.Email, nil
}
```

Wire into JMAP auth middleware and SMTP AUTH OAUTHBEARER (RFC 7628).

### 3.2.2 — SCIM 2.0 provisioning endpoint
Add HTTP handlers at `/scim/v2/Users` (RFC 7644):
- `POST /scim/v2/Users` — create user
- `GET /scim/v2/Users/{id}` — get user
- `PATCH /scim/v2/Users/{id}` — update (active=false → disable)
- `DELETE /scim/v2/Users/{id}` — delete

Map SCIM `userName`, `emails[primary]`, `active` to local `User` struct.
Protect with Bearer token (shared secret or OIDC-signed token from IdP).
